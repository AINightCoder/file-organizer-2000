# Knowledge Test Tab 使用说明

## 概述

新添加的 **Knowledge Test** 标签页提供了一个友好的界面，用于测试和验证知识管理功能（原子化笔记拆分）。

## 位置

插件设置 → Knowledge Test 标签页（最右侧）

## 功能特性

### 1. 配置状态显示

实时显示当前知识管理功能的配置状态：
- ✅ 知识管理功能是否启用
- ✅ 原子化拆分是否启用
- 📊 最大笔记长度
- 📊 最小笔记长度
- 📊 拆分策略

### 2. 两种测试模式

#### 🧪 测试拆分（推荐先用）
- **功能**：仅测试AI拆分能力，不创建实际文件
- **用途**：验证拆分效果、调试配置
- **安全**：不会修改vault内容
- **速度**：快速，仅调用AI服务
- **适用场景**：
  - 首次测试功能
  - 调整拆分提示词
  - 验证拆分质量

#### 🚀 真实处理测试
- **功能**：创建测试文件并走完整处理流程
- **用途**：端到端测试整个知识管理流程
- **包含**：拆分 → 分类 → 重命名 → 格式化 → 标签推荐
- **注意**：会删除原笔记，创建拆分后的文件
- **适用场景**：
  - 验证完整流程
  - 测试与其他功能的集成
  - 正式使用前的最后验证

### 3. 详细的处理日志

实时显示处理过程：
- ⏱️ 时间戳
- 📝 每个步骤的状态
- ✅ 成功信息
- ❌ 错误信息
- 📊 拆分结果统计

### 4. 可视化的拆分结果

测试拆分后会显示：
- 📈 原始长度统计
- 🔢 拆分笔记数量
- 📏 平均笔记长度
- 📑 每个拆分笔记的详情：
  - 标题
  - 长度
  - 知识点描述
  - 内容预览

## 使用流程

### 步骤1：确保功能已启用

1. 切换到 **Advanced** 标签页
2. 找到"知识管理功能"区域
3. 启用以下开关：
   - ☑️ 启用知识管理功能
   - ☑️ 启用原子化拆分

### 步骤2：准备测试内容

在 **Knowledge Test** 标签页：

1. **输入文件名**
   - 默认：`Flutter开发笔记`
   - 可自定义

2. **输入或修改测试内容**
   - 默认提供了一个示例笔记
   - 包含3个明显的知识点：
     - 什么是Flutter
     - Flutter的优势
     - 如何安装Flutter
   - 可以替换为自己的内容

### 步骤3：执行测试拆分

1. 点击 **"测试拆分"** 按钮
2. 观察处理日志
3. 查看拆分结果

## 测试建议

### 1. 基础测试用例

#### ✅ 多知识点笔记（应该拆分）
```markdown
# 测试笔记

## 知识点1
内容1...

## 知识点2
内容2...

## 知识点3
内容3...
```

**预期结果**：拆分为3个笔记

#### ✅ 单一知识点笔记（不应拆分）
```markdown
# Flutter简介

Flutter是一个跨平台框架...
（只有一个主题）
```

**预期结果**：返回1个笔记（原内容）

#### ✅ 超长笔记（应按长度拆分）
```markdown
# 超长技术文档

[3000+ 字符的单一主题内容]
```

**预期结果**：按长度拆分为多个片段

#### ✅ 短笔记（不应拆分）
```markdown
# 快速笔记

一个简短的想法。
```

**预期结果**：不拆分，正常处理

### 2. 边界测试用例

- 恰好等于 minNoteLength 的内容
- 恰好等于 maxNoteLength 的内容
- 包含代码块的笔记
- 包含图片的笔记
- 包含表格的笔记

### 3. 错误场景测试

- AI服务不可用
- 网络中断
- 无效的配置
- 空内容
- 特殊字符

## 故障排查

### 问题1：点击"测试拆分"无反应

**检查项**：
- [ ] 是否启用了知识管理功能？
- [ ] 测试内容是否为空？
- [ ] 是否正在处理中（按钮显示"测试中..."）？
- [ ] 查看浏览器控制台是否有错误

**解决方法**：
1. 确保在 Advanced 标签页启用功能
2. 输入测试内容
3. 等待上次操作完成

### 问题2：拆分失败

**日志示例**：
```
[10:30:20] ❌ 拆分失败: Failed to split into atomic notes
```

**可能原因**：
- AI服务未配置或无法访问
- API密钥无效
- 网络问题
- 内容格式问题

**解决方法**：
1. 检查 AI 模型配置
2. 验证 API 密钥
3. 检查网络连接
4. 查看完整的错误信息

### 问题3：拆分质量不理想

**表现**：
- 拆分不准确
- 知识点识别错误
- 内容截断

**解决方法**：
1. 使用更强大的 AI 模型
2. 在 Advanced 标签页调整拆分提示词
3. 优化测试内容的结构和标题
4. 调整 minNoteLength 和 maxNoteLength

## 最佳实践

### 1. 测试流程

```
准备内容 → 测试拆分 → 查看结果 → 调整配置 → 再次测试 → 真实处理
```

### 2. 内容准备

- ✅ 使用清晰的标题层级（#、##、###）
- ✅ 每个知识点独立成段
- ✅ 避免过度嵌套
- ✅ 保持合理的内容长度

### 3. 配置优化

根据测试结果调整：
- minNoteLength: 太多小笔记 → 增加
- maxNoteLength: 笔记太长 → 减少
- 拆分提示词: 效果不理想 → 自定义

### 4. 迭代改进

1. 从简单内容开始测试
2. 逐步增加复杂度
3. 观察拆分模式
4. 总结最佳实践
5. 应用到实际笔记

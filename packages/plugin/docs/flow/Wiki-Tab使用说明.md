# Wiki Tab 使用说明

## 概述

**Wiki Tab** 是一个全新的侧边栏标签页，与 Organizer 和 Inbox 处于同级位置，专门用于管理和处理当前打开的笔记。它提供了直观的界面来预览和应用知识管理功能（原子化拆分）。

## 位置

**侧边栏** → Fo2k Assistant → **Wiki** 标签页

```
┌─────────────────────────────────┐
│ Organizer | Inbox | Wiki       │ ← 标签栏
├─────────────────────────────────┤
│                                 │
│      Wiki Manager 界面          │
│                                 │
└─────────────────────────────────┘
```

## 核心功能

### 1. 当前笔记信息显示 📄

实时显示当前打开笔记的详细信息：
- **文件名**：笔记的名称
- **路径**：文件在 vault 中的完整路径
- **长度**：笔记内容的字符数
- **状态指示**：根据长度显示建议
  - 🔴 太短：低于最小长度（不建议拆分）
  - 🟢 适中：长度合适
  - 🟡 较长：建议考虑拆分

### 2. 配置状态展示 ⚙️

当知识管理功能启用时，显示：
- 知识管理功能状态
- 原子化拆分状态
- 长度限制配置

### 3. 三个核心操作 🚀

#### 📋 预览拆分
- **功能**：分析当前笔记，AI识别知识点
- **安全**：仅预览，不修改文件
- **输出**：
  - 拆分笔记数量
  - 每个笔记的标题、长度、知识点
  - 内容预览
- **适用**：所有启用知识管理的笔记

#### ✅ 应用拆分
- **功能**：执行拆分，创建新笔记
- **操作**：
  1. 创建所有拆分后的笔记
  2. 删除原笔记
  3. 打开第一个拆分笔记
- **前提**：必须先预览拆分
- **警告**：操作不可撤销

#### 📥 移动到 Inbox 处理
- **功能**：将当前笔记移动到 Inbox
- **效果**：笔记进入完整的自动处理流程
- **包含**：拆分 + 分类 + 重命名 + 格式化 + 标签

## 使用流程

### 基础流程

```
打开笔记 → 查看信息 → 预览拆分 → 查看结果 → 应用拆分
```

### 详细步骤

#### 步骤1：打开笔记
1. 在 Obsidian 中打开任意笔记
2. 打开侧边栏 Fo2k Assistant
3. 切换到 Wiki 标签页

## 使用场景

### 场景1：快速拆分单个笔记

**适用**：
- 临时需要拆分一个笔记
- 想要快速看到拆分效果
- 不想走完整的 Inbox 流程

**操作**：
```
打开笔记 → Wiki Tab → 预览拆分 → 应用拆分
```

### 场景2：批量处理前预览

**适用**：
- 不确定拆分效果
- 想先测试配置
- 需要调整拆分策略

**操作**：
```
打开笔记 → Wiki Tab → 预览拆分 → 调整配置 → 再次预览
```

### 场景3：完整流程处理

**适用**：
- 需要完整的知识管理流程
- 需要分类、标签、重命名等
- 批量处理多个笔记

**操作**：
```
打开笔记 → Wiki Tab → 移动到 Inbox 处理
```

## 与 Inbox 的区别

| 特性 | Wiki Tab | Inbox |
|------|---------|-------|
| 触发方式 | 手动选择笔记 | 自动监听文件夹 |
| 处理对象 | 当前打开的笔记 | Inbox 文件夹中的所有文件 |
| 预览功能 | ✅ 支持预览 | ❌ 自动处理 |
| 确认机制 | ✅ 需要确认 | ❌ 自动执行 |
| 处理流程 | 仅拆分 或 完整流程 | 完整流程 |
| 适用场景 | 单个笔记处理 | 批量自动处理 |
| 撤销能力 | 预览阶段可取消 | 无法预览 |

**选择建议**：
- 🎯 **单个笔记、需要预览** → 使用 Wiki Tab
- 🚀 **批量处理、全自动** → 使用 Inbox

## 界面元素详解

### 状态指示器

```
🔴 太短   - 低于 minNoteLength，不建议拆分
🟢 适中   - 长度合适，可以不拆分
🟡 较长   - 超过 maxNoteLength，建议拆分
```

### 按钮状态

```
📋 预览拆分
   ├─ 启用：笔记已打开 + 知识管理已启用
   ├─ 禁用：无笔记 或 功能未启用
   └─ 处理中：显示"分析中..."

✅ 应用拆分
   ├─ 显示：预览完成且有结果
   ├─ 禁用：正在处理中
   └─ 隐藏：未预览或无结果

📥 移动到 Inbox
   ├─ 启用：笔记已打开
   └─ 禁用：无笔记 或 正在处理
```

### 处理日志

```
颜色编码：
  ⏱️ [时间]     - 灰色：普通信息
  ✅           - 绿色：成功操作
  ❌           - 红色：错误信息
  ⚠️           - 黄色：警告信息
  ℹ️           - 蓝色：提示信息
```

## 常见问题

### Q1: 点击"预览拆分"没反应？

**检查项**：
1. ✅ 是否打开了笔记？
2. ✅ 是否启用了知识管理功能？
3. ✅ 笔记长度是否足够？
4. ✅ AI 服务是否配置正确？

**解决方法**：
- 查看日志了解具体原因
- 检查设置中的配置
- 确保网络连接正常

### Q2: 预览结果不满意怎么办？

**可以尝试**：
1. 调整拆分提示词
2. 修改笔记结构（添加清晰的标题）
3. 使用不同的 AI 模型
4. 调整长度限制参数

**不必担心**：
- 预览阶段不会修改文件
- 可以多次预览调整

### Q3: 应用拆分后能撤销吗？

**不可以**：
- 应用拆分会删除原笔记
- 操作不可撤销

**建议**：
1. 应用前仔细查看预览
2. 重要笔记先备份
3. 或者使用"移动到 Inbox"（保留更多控制）

### Q4: 拆分后的笔记在哪里？

**位置**：
- 与原笔记相同的文件夹
- 自动以知识点标题命名

**打开方式**：
- 应用拆分后会自动打开第一个笔记
- 其他笔记在同一文件夹中

### Q5: 如何处理失败？

**拆分失败**：
- 查看日志了解原因
- 检查 AI 服务配置
- 网络问题重试

**创建失败**：
- 检查文件权限
- 确保文件名有效
- 查看是否有同名文件冲突

### Q6: 可以批量处理吗？

**不可以**：
- Wiki Tab 设计用于单个笔记
- 每次只处理当前打开的笔记

**批量处理**：
- 使用 Inbox 功能
- 将笔记移动到 Inbox 文件夹

## 故障排查

### 问题：AI 分析很慢

**可能原因**：
- 网络延迟
- API 响应慢
- 笔记太长

**解决方法**：
1. 检查网络连接
2. 使用本地 AI 模型
3. 减少笔记长度

### 问题：知识点识别不准

**可能原因**：
- 笔记结构不清晰
- AI 模型能力有限
- 提示词不够准确

**解决方法**：
1. 优化笔记标题和结构
2. 使用更强大的 AI 模型
3. 自定义拆分提示词

### 问题：文件创建失败

**可能原因**：
- 文件名冲突
- 权限问题
- 磁盘空间不足

**解决方法**：
1. 检查是否有同名文件
2. 确保有写入权限
3. 释放磁盘空间

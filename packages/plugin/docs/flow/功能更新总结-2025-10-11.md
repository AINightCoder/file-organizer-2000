# 功能更新总结 - 2025-10-11

## 更新内容

### 1. ✅ Wiki Tab 行为优化

#### 变更说明
将 Wiki Tab 从"预览模式"改为"立即处理模式"，提供更流畅的工作流程。

#### 主要变更
- ❌ 移除了"预览拆分"和"应用拆分"两步操作
- ✅ 改为"立即处理"一步到位
- ✅ 所有拆分笔记自动移动到 Inbox 进行完整处理流程
- ✅ 单一知识点笔记也会移动到 Inbox 进行后续处理

#### 详细文档
参见：`docs/flow/Wiki-Tab更新说明.md`

---

### 2. ✅ Knowledge Test Tab 增强

#### 新增功能
在 Knowledge Test Tab 中添加了**自定义 AI 提示词配置**功能。

#### 功能特性

**可配置的提示词**：
1. 原子化拆分提示词 - 用于笔记拆分
2. 重命名提示词 - 用于笔记重命名
3. 文件夹分类提示词 - 用于笔记分类
4. 标签生成提示词 - 用于标签推荐

**操作功能**：
- 💾 保存到设置 - 将自定义提示词应用到插件全局设置
- 🔄 重置 - 恢复为当前设置中的提示词
- 可展开/折叠界面
- 测试时可选择使用自定义提示词或设置中的提示词

#### 使用场景
- 测试不同的提示词效果
- 优化 AI 生成质量
- 快速迭代和调试提示词

---

### 3. ✅ Advanced Tab 设置完善

#### 新增设置项

添加了完整的**知识管理功能设置区域**：

```
📚 知识管理功能
├── ☑️ 启用知识管理功能 (总开关)
└── (启用后显示以下选项)
    ├── ☑️ 启用原子化拆分
    ├── 🔢 最小笔记长度 (默认: 100)
    ├── 🔢 最大笔记长度 (默认: 3000)
    ├── 📋 拆分策略
    │   ├── 按知识点拆分
    │   ├── 按长度拆分
    │   └── 组合拆分（推荐）✅
    └── 📝 原子化拆分提示词 (可自定义)
```

#### 设置项说明

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用知识管理功能 | 总开关，必须启用才能使用 Wiki Tab 等功能 | ✅ true |
| 启用原子化拆分 | 是否自动拆分多知识点笔记 | ✅ true |
| 最小笔记长度 | 低于此长度不拆分（字符数） | 100 |
| 最大笔记长度 | 超过此长度建议拆分（字符数） | 3000 |
| 拆分策略 | atomic/length/both | both |
| 原子化拆分提示词 | AI 拆分时使用的提示词 | (默认提示词) |

---

### 4. ✅ 默认配置优化

#### 变更内容
将 `enableKnowledgeManagement` 的默认值从 `false` 改为 `true`。

#### 影响范围
- **新用户**：安装后知识管理功能默认启用
- **现有用户**：需要在 Advanced 标签页手动启用一次

#### 启用步骤（针对现有用户）
1. 打开插件设置
2. 切换到 **Advanced** 标签页
3. 向下滚动到"📚 知识管理功能"部分
4. 勾选 "启用知识管理功能"
5. 完成！Wiki Tab 的"立即处理"按钮即可使用

---

### 5. ✅ Wiki Tab 调试信息

#### 新增功能
在 Wiki Tab 的笔记信息区域添加了调试信息显示。

#### 显示内容
```
调试信息: activeFile=✓, isProcessing=✗, enableKM=✓
```

#### 用途
快速诊断"立即处理"按钮为何不可点击：
- `activeFile=✗` → 需要打开笔记
- `isProcessing=✓` → 正在处理，等待完成
- `enableKM=✗` → 需要在 Advanced 设置中启用知识管理功能

## 完整功能架构

### 三层处理系统

```
┌─────────────────────────────────────────────┐
│           Knowledge Test Tab                │
│         (测试和调试配置)                    │
│  • 测试拆分效果                             │
│  • 自定义 AI 提示词                         │
│  • 快速迭代优化                             │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│              Wiki Tab                       │
│         (手动触发 + 预览)                   │
│  • 立即处理当前笔记                         │
│  • 自动拆分（如需要）                       │
│  • 移动到 Inbox 进行完整处理                │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│              Inbox Tab                      │
│         (自动化处理队列)                    │
│  • 自动监听 Inbox 文件夹                    │
│  • 完整处理流程                             │
│  • 分类 + 重命名 + 格式化 + 标签            │
└─────────────────────────────────────────────┘
```

### 工作流程示例

**场景1：测试新配置**
```
Knowledge Test Tab → 修改提示词 → 测试拆分 → 查看效果 → 保存配置
```

**场景2：处理单个笔记**
```
打开笔记 → Wiki Tab → 立即处理 → 拆分并移动到 Inbox → Inbox 完成后续
```

**场景3：批量处理**
```
将笔记移动到 Inbox 文件夹 → Inbox Tab 自动处理 → 完成
```

## 常见问题

### Q1: Wiki Tab 的"立即处理"按钮不可点击？

**原因**：知识管理功能未启用

**解决方法**：
1. 打开插件设置
2. 切换到 Advanced 标签页
3. 向下滚动找到"📚 知识管理功能"
4. 勾选"启用知识管理功能"

**验证**：查看调试信息，应显示 `enableKM=✓`

---

### Q2: 如何自定义 AI 提示词？

**方法1**：在 Advanced Tab 中直接修改
- 找到"原子化拆分提示词"文本框
- 修改并保存

**方法2**：在 Knowledge Test Tab 中测试后保存
1. 展开"自定义 AI 提示词"
2. 修改提示词
3. 点击"测试拆分"查看效果
4. 满意后点击"💾 保存到设置"

---

### Q3: Wiki Tab 和 Inbox Tab 有什么区别？

| 特性 | Wiki Tab | Inbox Tab |
|------|----------|-----------|
| 触发方式 | 手动 | 自动 |
| 处理对象 | 当前打开的笔记 | Inbox 文件夹中的所有文件 |
| 确认机制 | 有确认对话框 | 自动执行 |
| 适用场景 | 单个重要笔记 | 批量自动处理 |

---

### Q4: 拆分后的笔记在哪里？

**Wiki Tab 处理后**：
1. 拆分笔记先创建在原笔记所在文件夹
2. 然后自动移动到 Inbox 文件夹
3. Inbox 自动处理：分类、重命名、标签等
4. 最终移动到对应的分类文件夹

**完整路径示例**：
```
原位置: Notes/Flutter开发笔记.md
  ↓ 拆分
临时: Notes/什么是Flutter.md (等3个文件)
  ↓ 移动
Inbox: .fileorganizer2000/Inbox/什么是Flutter.md
  ↓ 处理
最终: 1.Area/技术/什么是Flutter.md
```

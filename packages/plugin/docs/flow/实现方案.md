# File Organizer 2000 知识管理增强实现方案

## 一、项目背景与目标

### 1.1 背景

File Organizer 2000 当前是一个强大的文件自动化组织工具，具备多媒体处理、智能分类、自动重命名等功能。本方案旨在在保留现有优势的基础上，融入知识管理能力，实现从"文件组织工具"到"知识管理系统"的升级。

### 1.2 核心目标

- **原子化笔记管理**：支持将复杂笔记按知识点拆分为独立的原子化笔记
- **结构化知识库**：基于 `1.Area/2.Project/3.Archive` 三级分类体系
- **增强元数据**：符合知识管理最佳实践的元数据模板
- **智能关联**：自动关联 Roadmap，构建知识网络
- **向后兼容**：所有新功能可选启用，不影响现有用户

### 1.3 设计原则

1. **向后兼容** - 所有新功能通过配置开关控制
2. **渐进增强** - 分阶段实施，每个阶段独立可用
3. **复用优化** - 最大化复用现有代码和架构
4. **灵活配置** - 通过开关控制新旧功能
5. **性能优先** - 避免显著降低处理速度

### 2.1 现有管线流程

当前实现位于 `inbox/index.ts` 的 `processInboxFile` 方法，采用线性处理方式：


### 2.2 核心架构特点

- **上下文传递**：`ProcessingContext` 在步骤间传递，携带所有处理状态
- **统一执行器**：`executeStep` 函数统一处理步骤执行、错误处理、跳过逻辑
- **状态管理**：`RecordManager` 跟踪每个文件的处理状态和历史
- **队列管理**：`Queue` 类管理并发处理，支持媒体文件特殊限流
- **AI 服务**：`AIService` 提供统一的 AI 能力接口

## 三、核心设计理念

### 3.1 架构转变

**从线性处理改为递归处理**

```
旧架构：Inbox → 线性13步 → 完成

新架构：Inbox → 判断是否需要拆分
                ├─ 不拆分 → 线性处理 → 完成
                └─ 拆分 → 原子化拆分 → 删除原笔记 → 递归处理每个子笔记
```

### 3.2 拆分策略

**两级拆分机制：**

1. **知识点原子化拆分**（主要）
   - 基于 AI 识别独立知识点
   - 每个笔记专注一个核心概念
   - 保持语义完整性

2. **长度限制拆分**（辅助）
   - 单个笔记不超过 maxNoteLength（默认3000字）
   - 在段落边界智能分割
   - 保持上下文连贯性

### 3.3 递归处理逻辑

```typescript
async processInboxFile(file: TFile, hash?: string) {
  // ... 前置步骤（1-6）

  // 拆分判断点
  if (shouldSplitNote(context)) {
    // 执行拆分
    await atomicSplitStep(context);
    await lengthSplitStep(context);

    // 删除原笔记
    await deleteOriginalNoteStep(context);

    // 递归处理每个拆分后的笔记
    for (const splitNote of context.splitNotes) {
      const newFile = await createNoteFile(splitNote);
      const childContext = createChildContext(context, newFile, splitNote);
      await processInboxFile(newFile, childContext.hash); // 递归
    }
    return; // 不再继续处理原笔记
  }

  // ... 后续步骤（7-13）
}
```

### 5.3 AI 服务扩展

#### 5.3.1 新增 AI 方法（services/ai_service.ts）

```typescript
export class AIService {
  // ... 现有方法

  /**
   * 原子化拆分笔记
   * @param content 笔记内容
   * @param filename 原文件名
   * @param customPrompt 自定义提示词
   * @returns 拆分后的笔记数组
   */
  async splitIntoAtomicNotes(
    content: string,
    filename: string,
    customPrompt?: string
  ): Promise<AtomicNote[]> {
    const prompt = customPrompt || `分析以下笔记内容，按照单一知识点原则拆分成独立的原子化笔记。

要求：
1. 每个笔记专注一个核心概念或知识点
2. 保持每个笔记的语义完整性和独立性
3. 为每个笔记提供清晰的标题和知识点说明
4. 如果内容本身已经是单一知识点，返回包含原内容的单个笔记

原文件名：${filename}

笔记内容：
${content}

请以JSON数组格式返回，每个元素包含：
- title: 笔记标题（清晰、描述性强）
- content: 笔记内容（完整的markdown格式）
- knowledgePoint: 知识点描述（一句话说明核心概念）`;

    const model = this.getModel();

    const response = await model.generateContent({
      messages: [{ role: "user", content: prompt }],
      response_format: { type: "json_object" },
    });

    const result = JSON.parse(response.content);

    // 验证返回格式
    if (!Array.isArray(result.notes)) {
      throw new Error("AI返回格式错误：期望 { notes: [...] }");
    }

    return result.notes.map((note: any) => ({
      filename: note.title || "未命名笔记",
      content: note.content || "",
      knowledgePoint: note.knowledgePoint,
    }));
  }

  /**
   * 按长度智能拆分内容
   * @param content 内容
   * @param maxLength 最大长度
   * @returns 拆分后的内容片段
   */
  async splitByLength(
    content: string,
    maxLength: number = 3000
  ): Promise<string[]> {
    if (content.length <= maxLength) {
      return [content];
    }

    const prompt = `将以下内容在保持语义完整的前提下，按段落边界拆分为多个片段，每个片段不超过 ${maxLength} 字符。

要求：
1. 在段落或章节边界处拆分
2. 保持每个片段的上下文连贯性
3. 避免在句子中间截断
4. 如果某个段落本身超过限制，在合适的句子边界拆分

内容：
${content}

请以JSON数组格式返回片段列表：
{ "fragments": ["片段1", "片段2", ...] }`;

    const model = this.getModel();

    const response = await model.generateContent({
      messages: [{ role: "user", content: prompt }],
      response_format: { type: "json_object" },
    });

    const result = JSON.parse(response.content);

    if (!Array.isArray(result.fragments)) {
      throw new Error("AI返回格式错误");
    }

    return result.fragments;
  }
}
```

#### 5.4.1 新增步骤函数（inbox/index.ts）

```typescript
/**
 * 判断是否需要拆分笔记
 */
function shouldSplitNote(context: ProcessingContext): boolean {
  const settings = context.plugin.settings;

  // 功能未启用
  if (!settings.enableKnowledgeManagement) {
    return false;
  }

  // 已经是原子化笔记（避免无限递归）
  if (context.isAtomicNote) {
    logger.info("跳过拆分：已经是原子化笔记", { hash: context.hash });
    return false;
  }

  // 内容太短
  const contentLength = context.content?.length || 0;
  if (contentLength < settings.minNoteLength) {
    logger.info("跳过拆分：内容太短", {
      hash: context.hash,
      length: contentLength
    });
    return false;
  }

  // 非文本文件（媒体文件等）
  if (context.attachmentFile) {
    logger.info("跳过拆分：非文本文件", { hash: context.hash });
    return false;
  }

  return true;
}

/**
 * 知识点原子化拆分步骤
 */
async function atomicSplitStep(
  context: ProcessingContext
): Promise<ProcessingContext> {
  const settings = context.plugin.settings;

  // 检查是否启用原子化拆分
  if (!settings.enableAtomicSplit) {
    logger.info("跳过原子化拆分：功能未启用");
    return context;
  }

  logger.info("开始原子化拆分", {
    hash: context.hash,
    filename: context.containerFile.basename
  });

  try {
    // 调用AI服务进行拆分
    const aiService = new AIService({
      apiKey: settings.API_KEY,
      baseURL: settings.Model_BASE_URL,
      model: settings.Model_Name,
    });

    const atomicNotes = await aiService.splitIntoAtomicNotes(
      context.content,
      context.containerFile.basename,
      settings.atomicSplitPrompt
    );

    logger.info("原子化拆分完成", {
      hash: context.hash,
      count: atomicNotes.length
    });

    // 如果只返回一个笔记且内容相同，说明无需拆分
    if (atomicNotes.length === 1 &&
        atomicNotes[0].content.trim() === context.content.trim()) {
      logger.info("无需拆分：内容已是单一知识点");
      context.splitNotes = [];
      return context;
    }

    // 存储拆分结果
    context.splitNotes = atomicNotes.map((note, index) => ({
      filename: note.filename,
      content: note.content,
      knowledgePoint: note.knowledgePoint,
    }));

    return context;
  } catch (error) {
    logger.error("原子化拆分失败", error);
    // 拆分失败不应阻断流程，继续后续处理
    context.splitNotes = [];
    return context;
  }
}

/**
 * 按最大字数拆分步骤
 */
async function lengthSplitStep(
  context: ProcessingContext
): Promise<ProcessingContext> {
  const settings = context.plugin.settings;

  // 如果没有拆分结果，检查是否需要按长度拆分
  if (!context.splitNotes || context.splitNotes.length === 0) {
    const contentLength = context.content?.length || 0;

    if (contentLength > settings.maxNoteLength) {
      logger.info("开始按长度拆分", {
        hash: context.hash,
        length: contentLength,
        maxLength: settings.maxNoteLength
      });

      try {
        const aiService = new AIService({
          apiKey: settings.API_KEY,
          baseURL: settings.Model_BASE_URL,
          model: settings.Model_Name,
        });

        const fragments = await aiService.splitByLength(
          context.content,
          settings.maxNoteLength
        );

        logger.info("按长度拆分完成", {
          hash: context.hash,
          count: fragments.length
        });

        // 生成拆分笔记
        context.splitNotes = fragments.map((fragment, index) => ({
          filename: `${context.containerFile.basename} ${index + 1}`,
          content: fragment,
        }));
      } catch (error) {
        logger.error("按长度拆分失败", error);
        context.splitNotes = [];
      }
    }
  } else {
    // 对每个原子化拆分的笔记检查长度
    const newSplitNotes: typeof context.splitNotes = [];

    for (const note of context.splitNotes) {
      if (note.content.length > settings.maxNoteLength) {
        logger.info("原子笔记超长，进行长度拆分", {
          filename: note.filename,
          length: note.content.length,
        });

        try {
          const aiService = new AIService({
            apiKey: settings.API_KEY,
            baseURL: settings.Model_BASE_URL,
            model: settings.Model_Name,
          });

          const fragments = await aiService.splitByLength(
            note.content,
            settings.maxNoteLength
          );

          // 为每个片段生成独立笔记
          fragments.forEach((fragment, index) => {
            newSplitNotes.push({
              filename: `${note.filename} ${index + 1}`,
              content: fragment,
              knowledgePoint: note.knowledgePoint,
            });
          });
        } catch (error) {
          logger.error("原子笔记长度拆分失败", error);
          // 失败时保留原笔记
          newSplitNotes.push(note);
        }
      } else {
        newSplitNotes.push(note);
      }
    }

    context.splitNotes = newSplitNotes;
  }

  return context;
}

/**
 * 删除原笔记步骤
 */
async function deleteOriginalNoteStep(
  context: ProcessingContext
): Promise<ProcessingContext> {
  // 只有在成功拆分时才删除
  if (context.splitNotes && context.splitNotes.length > 0) {
    logger.info("删除原笔记", {
      hash: context.hash,
      filename: context.containerFile.basename
    });

    try {
      await context.plugin.app.vault.delete(context.containerFile);

      // 如果有附件文件也一起处理
      if (context.attachmentFile &&
          context.attachmentFile !== context.containerFile) {
        // 保留附件，后续会附加到第一个拆分笔记
      }

      logger.info("原笔记已删除", { hash: context.hash });
    } catch (error) {
      logger.error("删除原笔记失败", error);
      throw error;
    }
  }

  return context;
}

/**
 * 创建子上下文（用于递归处理）
 */
function createChildContext(
  parentContext: ProcessingContext,
  newFile: TFile,
  splitNote: ProcessingContext["splitNotes"][0]
): ProcessingContext {
  const childHash = parentContext.idService.generateFileHash(newFile);

  return {
    inboxFile: newFile,
    containerFile: newFile,
    hash: childHash,
    content: splitNote.content,
    plugin: parentContext.plugin,
    recordManager: parentContext.recordManager,
    idService: parentContext.idService,
    queue: parentContext.queue,

    // 标记为原子化笔记（避免无限递归）
    isAtomicNote: true,
    parentHash: parentContext.hash,
  };
}
```

```typescript
  try {
    // ===== 前置步骤（1-6）=====
    await executeStep(context, startProcessing, Action.START, Action.ERROR_START);
    await executeStep(context, hasValidFileStep, Action.VALIDATE, Action.ERROR_VALIDATE);
    await executeStep(context, getContainerFileStep, Action.CONTAINER, Action.ERROR_CONTAINER);
    await executeStep(context, moveAttachmentFile, Action.MOVING_ATTACHMENT, Action.ERROR_MOVING_ATTACHMENT);
    await executeStep(context, getContentStep, Action.EXTRACT, Action.ERROR_EXTRACT);
    await executeStep(context, cleanupStep, Action.CLEANUP, Action.ERROR_CLEANUP);

    // ===== 拆分判断点 =====
    if (shouldSplitNote(context)) {
      logger.info("开始笔记拆分流程", { hash: context.hash });

      // 执行拆分步骤
      await executeStep(context, atomicSplitStep, Action.ATOMIC_SPLIT, Action.ERROR_ATOMIC_SPLIT);
      await executeStep(context, lengthSplitStep, Action.LENGTH_SPLIT, Action.ERROR_LENGTH_SPLIT);

      // 如果成功拆分
      if (context.splitNotes && context.splitNotes.length > 0) {
        logger.info("拆分成功，开始递归处理", {
          hash: context.hash,
          count: context.splitNotes.length,
        });

        // 删除原笔记
        await executeStep(context, deleteOriginalNoteStep, Action.DELETE_ORIGINAL, Action.ERROR_DELETE_ORIGINAL);

        // 递归处理每个拆分后的笔记
        for (let i = 0; i < context.splitNotes.length; i++) {
          const splitNote = context.splitNotes[i];

          logger.info("处理拆分笔记", {
            index: i + 1,
            total: context.splitNotes.length,
            filename: splitNote.filename,
          });

          try {
            // 创建新文件（在inbox目录）
            const newFile = await safeCreate(
              context.plugin.app,
              `${context.plugin.settings.pathToWatch}/${splitNote.filename}.md`,
              splitNote.content
            );

            // 如果是第一个笔记且有附件，附加附件
            if (i === 0 && context.attachmentFile) {
              await context.plugin.app.vault.append(
                newFile,
                `\n\n![[${context.attachmentFile.name}]]`
              );
            }

            // 创建子上下文并递归处理
            const childContext = createChildContext(context, newFile, splitNote);
            context.recordManager.startTracking(childContext.hash, splitNote.filename);

            // 递归调用（子笔记会被标记为 isAtomicNote，不会再次拆分）
            await this.processInboxFile(newFile, childContext.hash);

          } catch (error) {
            logger.error("处理拆分笔记失败", {
              index: i + 1,
              filename: splitNote.filename,
              error,
            });
            // 继续处理下一个笔记
          }
        }

        // 标记原笔记处理完成
        context.recordManager.setStatus(context.hash, "completed");
        return; // 不再继续处理原笔记
      }
    }

    // ===== 后续步骤（7-13）- 正常处理流程 =====
    await executeStep(context, recommendClassificationStep, Action.CLASSIFY, Action.ERROR_CLASSIFY);
    await executeStep(context, recommendFolderStep, Action.MOVING, Action.ERROR_MOVING);
    await executeStep(context, recommendNameStep, Action.RENAME, Action.ERROR_RENAME);
    await executeStep(context, formatContentStep, Action.FORMATTING, Action.ERROR_FORMATTING);
    await executeStep(context, appendAttachmentStep, Action.APPEND, Action.ERROR_APPEND);
    await executeStep(context, recommendTagsStep, Action.TAGGING, Action.ERROR_TAGGING);
    await executeStep(context, completeProcessing, Action.COMPLETED, Action.ERROR_COMPLETE);

  } catch (error) {
    await handleError(error, context);
    logger.error("处理文件失败:", error);
  }
}
```

```typescript
  case Action.ERROR_ATOMIC_SPLIT:
  case Action.ERROR_LENGTH_SPLIT:

      hash: context.hash,
      error: error.message,

    break;
```

#### 5.5.2 回滚机制

```typescript
/**
 * 回滚拆分笔记（当删除原笔记失败时）
 */
async function rollbackSplitNotes(context: ProcessingContext): Promise<void> {
  if (!context.splitNotes || context.splitNotes.length === 0) {
    return;
  }

  logger.info("开始回滚拆分笔记", {
    hash: context.hash,
    count: context.splitNotes.length,
  });

  for (const splitNote of context.splitNotes) {
    try {
      const filePath = `${context.plugin.settings.pathToWatch}/${splitNote.filename}.md`;
      const file = context.plugin.app.vault.getAbstractFileByPath(filePath);

      if (file instanceof TFile) {
        await context.plugin.app.vault.delete(file);
        logger.info("已删除拆分笔记", { filename: splitNote.filename });
      }
    } catch (error) {
      logger.error("删除拆分笔记失败", {
        filename: splitNote.filename,
        error,
      });
    }
  }
}
```

## 十、总结

本实现方案基于 File Organizer 2000 现有架构，采用渐进式增强策略，分阶段实现知识管理功能。阶段 1 聚焦于核心的原子化拆分能力，建立递归处理架构，为后续阶段奠定基础。

**核心优势：**
1. **向后兼容** - 不影响现有用户
2. **架构清晰** - 复用现有设计模式
3. **风险可控** - 分阶段实施，每阶段独立可用
4. **扩展性强** - 预留后续优化空间

**关键成功因素：**
1. AI 拆分质量（prompt 优化）
2. 错误处理和回滚机制
3. 性能优化（避免阻塞）
4. 用户体验（配置简单、结果符合预期）

建议先完成阶段 1 的 MVP 实现，经过充分测试和用户反馈后，再逐步推进后续阶段。

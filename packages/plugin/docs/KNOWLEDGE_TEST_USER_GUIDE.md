## 🎨 自定义提示词

### 展开提示词面板

点击 **⚙️ 自定义 AI 提示词 (可选) ▶** 展开面板

### 可配置的提示词

1. **原子化拆分提示词**
   - 用于: 知识点拆分（步骤5）
   - 影响: 拆分粒度和笔记数量

2. **重命名提示词**
   - 用于: 文件重命名（步骤8）
   - 影响: 生成的文件名

3. **文件夹分类提示词**
   - 用于: 文件夹推荐（步骤11）
   - 影响: 推荐的目标文件夹

4. **标签生成提示词**
   - 用于: 标签推荐
   - 影响: 生成的标签

### 使用自定义提示词

```
1. 展开提示词面板
2. 修改提示词内容
3. 点击 [💾 保存到设置]  ← 保存到插件设置（全局生效）
   或
   直接测试（仅本次测试使用）
```

### 提示词优化流程

```
1. 修改提示词
   ↓
2. [🎯 完整流程测试]
   ↓
3. 查看对应步骤的效果
   ↓
4. 不满意？返回步骤1
   满意？点击 [💾 保存到设置]
```

## 📊 理解测试结果

### 步骤状态图标

| 图标 | 状态 | 含义 |
|------|------|------|
| ✅ | success | 步骤执行成功 |
| ❌ | failed | 步骤执行失败 |
| ⚠️ | warning | 执行成功但有警告 |
| ℹ️ | skipped | 步骤被跳过 |

### 状态颜色

- 🟢 **绿色** - 成功
- 🔴 **红色** - 失败（需要处理）
- 🟡 **黄色** - 警告（可能需要注意）
- ⚪ **灰色** - 跳过（正常）

### 常见结果解读

#### ✅ 原子化拆分成功，共生成 3 个笔记
```
→ AI 将内容拆分为 3 个独立知识点
→ 每个笔记都是完整的、可独立理解的
→ 查看笔记列表了解拆分细节
```

#### ⚠️ 有笔记超过最大长度限制
```
→ 某些拆分后的笔记仍然超长
→ 实际处理时会进行长度拆分
→ 建议: 调整拆分提示词或增加最大长度
```

#### ❌ AI服务未初始化
```
→ API Key 未配置或无效
→ 解决: 检查设置中的 AI 配置
```

#### ℹ️ 跳过（测试文件为 Markdown）
```
→ 正常跳过，不是错误
→ 某些步骤仅对媒体文件有效
```

## 🔍 常见问题排查

### Q1: 点击测试按钮没反应？

**检查项**:
1. ✅ 知识管理功能是否启用？
2. ✅ 测试内容是否为空？
3. ✅ 查看浏览器控制台是否有错误

### Q2: 拆分失败？

**可能原因**:
1. ❌ AI 服务未初始化
   - 解决: 配置 API Key
2. ❌ 内容过长或过短
   - 解决: 调整内容长度
3. ❌ 网络问题
   - 解决: 检查网络连接

### Q3: 为什么有些步骤显示"跳过"？

**正常情况**:
- 移动附件 - MD 文件没有附件
- 附加附件 - 测试文件无附件
- 内容格式化 - 需要完整流程支持
- Roadmap关联 - 需要知识图谱支持

### Q4: 如何调试重命名效果不好？

**步骤**:
```
1. 展开自定义提示词面板
2. 修改"重命名提示词"
3. [🎯 完整流程测试]
4. 查看步骤8的重命名建议
5. 满意后保存提示词
```

### Q5: 测试文件会留下吗？

**回答**:
- 🔬 测试拆分: 会清理
- 🎯 完整流程测试: 会清理
- ✅ 真实处理测试: 不会清理（按真实流程处理）

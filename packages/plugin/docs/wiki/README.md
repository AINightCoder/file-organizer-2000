## 关键概念

### 收件箱 (Inbox)
监控指定文件夹，自动处理新添加的文件。

### 处理管线 (Pipeline)
文件处理经过的一系列步骤，每个步骤独立且可配置。

### 容器文件 (Container File)
为媒体文件（PDF、图像、音频）创建的 Markdown 文件，包含提取的内容和媒体链接。

### AI 推荐
使用 AI 模型生成标签、标题、文件夹和分类建议。

### 并发控制
限制同时处理的文件数量，避免资源耗尽。
- 常规文件：最多 5 个
- 媒体文件：最多 2 个

### 状态跟踪
使用 RecordManager 跟踪每个文件的处理状态和历史。

## 常见问题

### Q1: 文件为什么被旁路了？
**A:** 文件可能因为以下原因被旁路：
- 文件类型不支持
- 内容太短（< 5 字符）
- 无法提取内容

查看：[文件处理流程](./文件处理流程.md) → 跳过逻辑

### Q2: AI 推荐不准确怎么办？
**A:** 可以通过以下方式优化：
- 调整内容截取字符数（`contentCutoffChars`）
- 使用自定义指令（`customTagInstructions` 等）
- 更换更强大的 AI 模型

查看：[AI 服务流程](./AI服务流程.md) → 配置建议

### Q3: 如何添加新的 AI 提供商？
**A:** 参考现有提供商的实现：
1. 在 `initializeModels()` 中添加新提供商
2. 配置 API 密钥和基础 URL
3. 添加到 `models` 字典

查看：[AI 服务流程](./AI服务流程.md) → AI 提供商配置

### Q4: 媒体文件处理太慢？
**A:** 可以优化：
- 增加媒体并发数（谨慎）
- 减少图像压缩质量
- 限制 PDF 提取页数

查看：[多媒体处理流程](./多媒体处理流程.md) → 性能优化

### Q5: 如何自定义处理流程？
**A:** 通过配置启用/禁用各个步骤：
- `enableDocumentClassification` - 分类和格式化
- `enableFileRenaming` - 文件重命名
- `useSimilarTags` - 标签推荐

查看：[文件处理流程](./文件处理流程.md) → 跳过逻辑

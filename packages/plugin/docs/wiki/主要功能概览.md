# File Organizer 2000 - 主要功能概览

## 项目简介

File Organizer 2000 是一个基于 AI 的 Obsidian 插件，用于智能化地组织和管理文件。插件通过监控指定的收件箱文件夹，自动处理新文件，包括分类、重命名、移动到合适的文件夹、添加标签以及格式化内容等。

## 核心功能

### 1. 自动文件处理 (Auto File Processing)

**功能描述：**
- 监控指定的收件箱文件夹（`pathToWatch`）
- 当新文件创建或移动到收件箱时，自动触发处理流程
- 使用队列系统管理文件处理，支持并发处理
- 支持媒体文件的特殊处理（限制并发数）

**关键组件：**
- `Inbox` 类：管理文件队列和处理流程
- `Queue` 类：实现文件处理队列
- `RecordManager` 类：跟踪文件处理状态

**配置项：**
- `enableAutoProcessing`：是否启用自动处理
- `pathToWatch`：收件箱文件夹路径
- 并发限制：常规文件 5 个，媒体文件 2 个

---

### 2. AI 文档分类 (AI Document Classification)

**功能描述：**
- 基于文件内容自动分类文档
- 根据预定义的模板（templates）进行分类
- 返回文档类型、置信度和分类理由

**工作流程：**
1. 读取文件内容（截取前 N 个字符）
2. 获取所有可用的模板名称
3. 调用 AI API 进行分类
4. 返回最匹配的文档类型

**关键方法：**
- `classifyContentV2(content, classifications)` - 执行分类
- `getTemplateNames()` - 获取模板列表

**配置项：**
- `enableDocumentClassification`：是否启用文档分类
- `templatePaths`：模板文件夹路径
- `contentCutoffChars`：内容截取字符数

---

### 3. AI 文件重命名 (AI File Renaming)

**功能描述：**
- 基于文件内容智能推荐新文件名
- 返回多个命名建议，包括评分和理由
- 自动应用最高分的文件名

**工作流程：**
1. 提取文件内容
2. 调用 AI 服务生成标题建议
3. 返回按评分排序的建议列表
4. 应用最高分的文件名（如果与当前名称不同）

**关键方法：**
- `recommendName(content, fileName)` - 生成命名建议
- `AIService.generateTitle()` - AI 生成标题

**配置项：**
- `enableFileRenaming`：是否启用文件重命名
- `renameInstructions`：自定义重命名指令

---

### 4. AI 文件夹推荐 (AI Folder Recommendation)

**功能描述：**
- 基于文件内容推荐目标文件夹
- 可以推荐现有文件夹或创建新文件夹
- 返回多个文件夹建议，包括评分和理由

**工作流程：**
1. 获取所有用户文件夹列表（排除忽略的文件夹）
2. 调用 AI 服务推荐文件夹
3. 返回按评分排序的建议列表
4. 自动移动文件到最高分的文件夹

**关键方法：**
- `recommendFolders(content, fileName)` - 生成文件夹建议
- `AIService.generateFolder()` - AI 生成文件夹推荐
- `getAllUserFolders()` - 获取可用文件夹列表

**配置项：**
- `ignoreFolders`：要忽略的文件夹列表
- `customFolderInstructions`：自定义文件夹推荐指令

---

### 5. AI 标签推荐 (AI Tag Recommendation)

**功能描述：**
- 基于文件内容推荐相关标签
- 优先使用现有标签，必要时创建新标签
- 支持将标签添加到 frontmatter 或文件内容中

**工作流程：**
1. 获取 vault 中所有现有标签
2. 调用 AI 服务推荐标签
3. 返回标签建议（包括是否为新标签、评分、理由）
4. 自动将标签添加到文件

**关键方法：**
- `recommendTags(content, filePath, existingTags)` - 生成标签建议
- `AIService.generateTags()` - AI 生成标签
- `appendTag(file, tag)` - 添加标签到文件

**配置项：**
- `useSimilarTags`：是否启用标签推荐
- `useSimilarTagsInFrontmatter`：是否添加到 frontmatter
- `customTagInstructions`：自定义标签推荐指令

---

### 6. AI 内容格式化 (AI Content Formatting)

**功能描述：**
- 根据文档分类和模板格式化内容
- 支持流式传输（实时更新）
- 可以在当前文件或分屏视图中格式化

**工作流程：**
1. 根据文档分类获取格式化模板
2. 备份原始文件
3. 调用 AI API 流式格式化内容
4. 实时更新文件内容
5. 添加原始文件的参考链接

**关键方法：**
- `formatContentV2(content, formattingInstruction)` - 格式化内容
- `formatStream()` - 流式格式化
- `streamFormatInCurrentNote()` - 在当前笔记中格式化
- `streamFormatInSplitView()` - 在分屏视图中格式化

**配置项：**
- `enableDocumentClassification`：是否启用（格式化依赖分类）
- `maxFormattingTokens`：最大格式化令牌数
- `templatePaths`：模板文件夹路径

---

### 7. 多媒体处理 (Multi-media Processing)

**功能描述：**
- **PDF 处理**：提取文本内容（前 10 页）
- **图像处理**：使用视觉 API 生成图像描述/OCR
- **音频处理**：转录音频为文本

**支持的格式：**
- 图像：jpg, jpeg, png, gif, webp, svg
- 音频：mp3, wav, m4a, ogg, 3gp, flac
- PDF：pdf

**工作流程：**

#### PDF 处理
1. 使用 PDF.js 加载 PDF
2. 提取前 10 页的文本内容
3. 返回文本

#### 图像处理
1. 检查图像大小和格式
2. 压缩图像（如果大于 1000px）
3. 转换为 base64
4. 调用视觉 API 生成描述
5. 返回描述文本

#### 音频处理
1. 读取音频文件
2. 调用转录 API（流式）
3. 实时返回转录文本
4. 附加到 Markdown 容器文件

**关键方法：**
- `extractTextFromPDF(file)` - 提取 PDF 文本
- `generateImageAnnotation(file)` - 生成图像描述
- `generateTranscriptFromAudio(file)` - 转录音频

**媒体文件处理特点：**
- 为媒体文件创建 Markdown 容器文件
- 将媒体文件移动到附件文件夹
- 在容器文件中嵌入媒体文件链接

---

### 8. 助手视图 (Assistant View)

**功能描述：**
- 提供用户界面查看和管理文件处理
- 包含两个主要标签页：
  - **Organizer Tab**：文件组织功能
  - **Inbox Tab**：收件箱状态和日志

**功能特点：**
- 查看处理队列状态
- 查看处理日志
- 手动触发文件处理
- 查看处理统计信息

**关键组件：**
- `AssistantViewWrapper` - 助手视图包装器
- `ORGANIZER_VIEW_TYPE` - 视图类型标识

**相关命令：**
- `open-organizer-tab` - 打开组织器标签
- `open-inbox-tab` - 打开收件箱标签

## 文件处理管线

文件处理遵循以下步骤（按顺序执行）：

1. **启动处理** (`startProcessing`)
2. **文件验证** (`hasValidFileStep`) - 检查文件类型是否支持
3. **容器创建** (`getContainerFileStep`) - 为媒体文件创建 Markdown 容器
4. **移动附件** (`moveAttachmentFile`) - 移动媒体文件到附件文件夹
5. **内容提取** (`getContentStep`) - 提取文件内容
6. **内容清理** (`cleanupStep`) - 清理 frontmatter、检查内容长度
7. **文档分类** (`recommendClassificationStep`) - AI 分类文档
8. **文件夹推荐** (`recommendFolderStep`) - AI 推荐并移动文件
9. **文件重命名** (`recommendNameStep`) - AI 推荐并重命名文件
10. **内容格式化** (`formatContentStep`) - 根据模板格式化内容
11. **附加附件** (`appendAttachmentStep`) - 附加媒体文件链接
12. **标签推荐** (`recommendTagsStep`) - AI 推荐并添加标签
13. **完成处理** (`completeProcessing`) - 标记为完成

**错误处理：**
- 每个步骤都有对应的错误处理
- 错误文件移动到错误文件夹或备份文件夹
- 使用 `RecordManager` 跟踪处理状态和错误

**跳过条件：**
- 根据配置项跳过某些步骤（如禁用分类、重命名等）
- 内容太短时跳过处理
- 不支持的文件类型被移动到旁路文件夹

## 配置项总览

### 路径配置
- `pathToWatch` - 收件箱文件夹
- `defaultDestinationPath` - 默认目标路径
- `attachmentsPath` - 附件文件夹
- `backupFolderPath` - 备份文件夹
- `templatePaths` - 模板文件夹
- `logFolderPath` - 日志文件夹
- `errorFilePath` - 错误文件路径
- `bypassedFilePath` - 旁路文件路径
- `referencePath` - 引用文件路径

### 功能开关
- `enableAutoProcessing` - 自动处理
- `enableDocumentClassification` - 文档分类
- `enableFileRenaming` - 文件重命名
- `useSimilarTags` - 标签推荐
- `enableFabric` - Fabric 功能

### AI 配置
- `API_KEY` - API 密钥
- `DEFAULT_MODEL` - 默认模型
- 各提供商的 API 密钥和模型配置

### 处理配置
- `contentCutoffChars` - 内容截取字符数
- `maxFormattingTokens` - 最大格式化令牌数
- `debugMode` - 调试模式
